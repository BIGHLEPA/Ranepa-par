Парсер расписания РАНХиГС в Google Calendar

Автоматический импорт расписания из личного кабинета студента в Google Calendar

Что делает:

1. Авторизуется на сайте my.ranepa.ru
2. Переходит на страницу расписания
3. Парсит данные о парах (название, время, тип, аудитория)
4. Создает события в Google Calendar с цветовой маркировкой:
   - Красный — онлайн-занятие (СДО)
   - Бирюзовый — офлайн-занятие

Как устроен код:



main.py Файл для запуска 
auth.py Авторизация на сайте 
schedule_finder.py  Навигация к расписанию 
change_week.py - Переключение недель (так как по умолчанию открывается текущая неделя, в функции можно указать число, положительное - на x недель вперед, отрицательное - на x недель назад)
а зачастую нужно расписание на следующую неделю
google_calendar_auth.py - OAuth 2.0 с Google 
google_calendar_events.py - Парсинг HTML + создание событий 
config.py -  Селекторы, URL, логин/пароль 
credentials.json - OAuth-клиент от Google  

Стек

selenium — веб-автоматизация
beautifulsoup4 — парсинг HTML
google-api-python-client — Google Calendar API
google-auth-oauthlib — OAuth 2.0

Как запустить (хоть скрипт и создавался для личного пользование, по идее его можно запустить у себя, но это не было протестированно)

1. Клонировать репозиторий
2. Установить зависимости: pip install selenium beautifulsoup4 google-api-python-client google-auth-oauthlib
3. Создать проект в Google Cloud Console, включить Calendar API
4. Скачать credentials.json и положить в корень проекта
5. В config.py указать свои логин/пароль от my.ranepa.ru
6. Запустить: python main.py

При первом запуске Google запросит авторизацию. Токен сохранится в "token.json" для следующих сессий. Как только токен истечет, нужно удалить файл "token.json" и заново зарегестрироваться (занимает пол минуты)
Новый файл с токеном появится сам.
